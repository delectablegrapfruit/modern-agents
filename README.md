# Vouch

Human taste across all media, as the antidote to machine content.

A visual prototype of a cross-media network of named human curators for film, books, music and art. You follow people, not feeds, and nothing is ranked by an algorithm.

## Run it

Open `index.html` in a browser. It is one self-contained file with no build step. On a wide screen it shows a phone frame with a screen index beside it. On a phone it runs full screen.

## Screens

| Screen | What it shows |
|---|---|
| Welcome | Growth by invitation: a named person invites you |
| Home | Picks from people you follow, newest first, and a feed that ends |
| Pick | The reason, the curator's signature, a disclosure, and where to get it |
| Curator | A list capped at ten picks, who vouches for them, and subscribe |
| Subscribe | The price and the 80/20 revenue split |
| Discover | New people found through vouches, sorted A to Z, with no ranking |
| Events | Ticketed events hosted by curators |
| Saved | One queue across all four media |
| Studio | A curator's payout (subscriptions, programming, events, links), B2B requests and vouch requests |
| New pick | Filling the last open slot, written in the curator's own words |

## Notes

- All people, works and numbers are fictional sample data. Nothing is saved or charged.
- Cover art is drawn in SVG at runtime, so there are no image files.
- Fonts load from Google Fonts: Bricolage Grotesque, Hanken Grotesk, DM Mono and Mrs Saint Delafield. Without a connection, the system fallbacks are used.
- The page follows the system light or dark setting. The screen index has a theme switch.
